# 通用重绘提示词(PNG → SVG)

面向任何科研图的通用提示词,适合交给 GPT / Kimi / Claude 等多模态大模型,把手头 PNG 高精度重绘为可编辑 SVG。它与具体案例无关;样式规则只有一条元规则——**忠实原图**,不预设任何固定风格。

把图片和下面这段提示词一起发给模型:

---

你是一名科研图表重绘专家。请以我提供的原始图片为唯一参考,将全部内容高精度重绘为 SVG 矢量图,最终文件能直接在 Microsoft PowerPoint 中打开并继续编辑。要求:

1. **画布精确**:`<svg>` 根元素带 `width="W" height="H" viewBox="0 0 W H"`(W/H 为原图像素尺寸),所有坐标以原图像素为基准,不缩放。
2. **整体保真**:布局、比例、文字、颜色、线条、箭头和元素位置与原图一致;先整体布局后局部细节。
3. **文字可编辑**:所有文字逐字照抄原图(大小写、上下标、希腊字母、标点),用 `<text>`/`<tspan>` 表达,禁止把文字画成路径;公式变量用斜体,上下标用 `<tspan>`。
4. **元素矢量**:图形、线条、箭头都是独立可编辑的矢量对象;禁止把整张图或大区域嵌入位图。照片、写实纹理等确实无法高质量矢量化的局部元素,用虚线占位矩形标记其位置和尺寸,不要强行描摹,也不要截图替代。
5. **箭头忠实原图**:每条箭头的头部样式、粗细、尺寸、弯折位置与连接关系复刻原图实际形态——原图是细线开口箭头就还原细线开口,是实心或块状就还原实心/块状,禁止套用统一固定风格;方向、起止和连接关系逐条与原图核对,不合并、不省略、不重叠。
6. **版面纪律**:文字与文字、文字与图形不重叠;连接线端点落在形状边缘或间隙,不穿越、不压盖文字;间距留白以原图为准。
7. **输出纯净**:只输出 SVG 代码本身,不要解释文字;无乱码、无错位、无元素缺失。

---

## 与管线合同的关系

本提示词面向独立使用场景。走 autofigure 管线(`prepare`/`ingest`/`convert`)时,`references/prompt-contract.md` 的硬性合同仍然适用;`autofigure prepare` 生成的案例级 `prompt.md` 会在本通用要求之上追加该案例的冻结哈希、区域任务和逐对象清点,这是案例专属的正式输入。
